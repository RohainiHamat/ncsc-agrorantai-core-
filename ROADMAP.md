# Roadmap NCSC AgroRantai – Governance-First AI

> Fokus fasa pertama: **kebolehbuktian tadbir urus**, bukan model besar.

## 2026 – Asas dan Bukti Konsep

| Tempoh | Aktiviti |
|--------|----------|
| Q1 | GitHub repo (Foundation Repository), README, lesen, rajah, PDF tesis |
| Q2 | RIF prototype v0.2, MBR v2 (lebih banyak peraturan) |
| Q3 | Simulator tadbir urus (Distributed Veto mock), integrasi dummy IoT |
| Q4 | Synthetic dataset lengkap, Kaggle notebook benchmark, kertas kerja teknikal pertama |

## 2027 – Simulasi dan Pengukuhan

- Pilot simulation dengan 5 jenis keputusan rantaian sejuk
- Eksperimen ketahanan (adversarial input, kegagalan nod)
- Penambahbaikan MBR berdasarkan pakar agro-makanan
- Reproducibility package

## 2028 – Rintis Nasional (Skala Terhad)

- Integrasi dengan satu rantaian bekalan sebenar (FAMA atau KPDN)
- Live audit dashboard
- Kertas putih untuk penggubal dasar

## 2029+ – Jangka Panjang

- Model AI ringan untuk ramalan residu
- Penyertaan piawaian antarabangsa
- Skala penuh nasional (jika dasar menyokong)

> Nota: Semua tarikh adalah target penyelidikan, bukan komitmen pengeluaran.
